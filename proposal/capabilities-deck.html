Our Approach

We start by reading the actual code — not just the previous vendor's notes. Our Phase 1 audit gives us a verified picture of what's there before any estimates are committed.

Restocking Recommendations

A new view that takes current stock levels and an operator-supplied budget ceiling, and produces purchase order recommendations across Meridian's three warehouses.

Built using the same Vue 3 + FastAPI patterns as the rest of the system — so Meridian IT inherits something they can maintain, not something foreign.

Assumption: demand forecasting is scoped as a future phase. This engagement uses current stock data.

Input: current stock levels + budget ceiling

Output: recommended purchase orders by warehouse and SKU
